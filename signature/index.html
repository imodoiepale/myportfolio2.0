Install in Gmail (desktop Chrome)

  1. Open https://imodoiepale.vercel.app/signature/ after Vercel has finished deploying. Confirm the globe and name render.
  2. Click Copy signature below. Do not use Ctrl+A on this whole page. That copies the instructions and extra padding, which is the empty space in the email.
  3. Gmail → gear → See all settings → General → scroll to Signature.
  4. Create new (name it James – Professional) or click the existing one. Click inside the signature editor, Ctrl+A, then Ctrl+V.
  5. Under Signature defaults, set it for new emails and for replies/forwards.
  6. Scroll to the bottom of Settings and click Save Changes. If you skip this, nothing sticks.
  7. Compose a new mail. If Gmail left a blank line above the globe, click that line and press Backspace until the signature sits flush.
  8. Send a test to yourself and tap every link (site, mail, phone, maps, socials).

The Gmail iOS/Android apps cannot paste a rich signature. Set it on desktop; the phone then uses that same signature. If images are broken, the deploy has not finished or you copied from a local file.
